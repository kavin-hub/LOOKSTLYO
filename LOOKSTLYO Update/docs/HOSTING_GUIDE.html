⚡ Quick Start (5 Minutes)

Step 1: Create GitHub Account

Visit github.com and sign up (if not already done)

Step 2: Create New Repository

  • Click "New" button
  • Repository name: lookstylo-fashion
  • Description: "Official Lookstylo Fashion Website"
  • Select "Public"
  • Click "Create repository"

Step 3: Upload Files

Option A: Using GitHub Web Interface (Easiest)

  • Click "Add file" → "Upload files"
  • Drag & drop all files
  • Commit changes

Option B: Using Command Line (Advanced)

git clone https://github.com/yourusername/lookstylo-fashion.git cd lookstylo-fashion # Copy all files here git add . git commit -m "Initial commit: Lookstylo Fashion" git push -u origin main

Step 4: Enable GitHub Pages

  • Go to Repository Settings
  • Scroll to "Pages" section
  • Select "main" branch
  • Click Save
  • Wait 1-2 minutes for deployment

Step 5: Visit Your Website

Your site will be live at:
https://yourusername.github.io/lookstylo-fashion

🆘 Troubleshooting

Site not appearing after upload?

  • Wait 1-2 minutes for GitHub to deploy
  • Clear browser cache (Ctrl+Shift+Del)
  • Check Pages settings: settings/pages
  • Verify branch is "main"

Images not loading?

  • Make sure all image files are uploaded
  • Check file names match HTML references
  • Verify image paths are correct

Admin dashboard not working?

  • Check browser console (F12) for errors
  • Verify JavaScript is enabled
  • Try incognito/private browsing
  • Clear localStorage and try again
